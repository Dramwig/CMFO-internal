# 论文规划

## 1. 一句话论文

CMFO 将文本和图像表示为各自原生坐标域上的函数场，并用无持久网格身份的耦合积分算子交互，从而在保持多模态任务性能的同时实现对未见数值离散的稳定推理与收敛。

这句话只有在 C1–C4 获得证据后才能作为最终结论；当前是待验证论文假设。

## 2. 审稿人应带走的三个结论

1. **问题重要且此前定义不充分**：可变序列长度不等于离散化不变性，多模态模型缺少针对内部数值网格的系统定义和评价。
2. **方法差异清楚**：CMFO 保留模态原生域，以参数与网格无关的场算子计算，不依赖固定 patch、统一序列或持久 latent slots。
3. **证据可复核**：在匹配预算下，CMFO 对分辨率、节点数量和布局 shift 更稳定，且这种收益不是普通增强、坐标编码或容量差异造成的。

## 3. 贡献表述草案

### Contribution 1：形式化

定义多模态离散化不变性，区分边界观测、内部求积节点和输出查询，并给出文本–图像原生域函数状态的统一形式。

### Contribution 2：方法

提出 coupled multimodal field operator：连续 lifting、模态内局部/低秩全局积分、跨域积分和场读取头；参数不依赖求积网格，节点无持久语义身份。

### Contribution 3：证据

建立跨节点数、采样布局和图像分辨率的评价协议，使用可控与真实任务、匹配强基线和关键消融验证一致性、收敛、任务性能与效率权衡。

可选的理论误差界只有在证明和实现完全对应时列为独立贡献。

## 4. 不应使用的过度主张

- “首次消除所有 token/patch/离散性”。
- “连续模型天然理解无限分辨率”。
- “语义实体必然从场动力学涌现”。
- “普通 attention 不是算子而 CMFO 才是”。
- “一次实验即可证明收敛到真实连续解”。
- “对所有模态和所有任务通用”。

更准确的表述是：内部计算不依赖持久离散语义索引；有限节点是可替换的数值近似；性质通过定义、条件和实验范围限定。

## 5. 论文结构

### 1. Introduction

- 固定离散表示的普遍性与真正问题。
- 可变长度为何不足以回答网格一致性。
- CMFO 的核心设计。
- 三项贡献和关键结果；结果未完成前保留占位符。

### 2. Problem Setup

- 原生坐标域、观测测度、隐场、求积点和查询点。
- discretization invariance、operator consistency、modality-native geometry 的定义。
- 文本是离散边界数据的限定。

### 3. Method

- continuous lifting；
- intra-modal local/global operators；
- cross-modal coupled operators；
- residual discretization 与复杂度；
- 训练的一致性目标和任务头。

### 4. Analysis

- 参数的网格独立性；
- 求积一致性/误差传播命题；
- 计算复杂度与实现限制。

### 5. Experiments

- 可控场景与真实任务；
- 强基线和公平协议；
- 主任务性能；
- 分辨率/节点数/布局外推；
- 收敛与效率；
- 消融、压力测试和失败案例。

### 6. Related Work

- neural operators；
- neural fields 与 coordinate networks；
- token/patch-free 与 byte/pixel models；
- multimodal latent/cross-attention；
- resolution robustness。

### 7. Limitations and Broader Impact

- 文本符号离散性；
- 数值成本和高频细节；
- 训练规模、数据偏差与适用范围；
- 不能由当前实验支持的音频、视频和生成结论。

## 6. 图表计划

### 必须图

1. **概念图**：观测点 → 模态原生场 → 耦合算子 → 输出场；明确求积点无持久身份。
2. **架构图**：一个 operator block 的局部、低秩全局和双向跨模态路径。
3. **核心曲线**：任务性能与场一致性随节点数/分辨率变化。
4. **采样布局热图或曲线**：规则、抖动、随机、非均匀网格下的稳健性。
5. **精度–效率前沿**：性能、FLOPs、显存或吞吐的权衡。
6. **定性图**：密集预测在多分辨率下的结果与失败案例。

### 必须表

1. 最近相关工作属性对比，不使用含糊勾选项。
2. 分布内主任务结果，参数/FLOPs 双匹配。
3. 分布外离散结果。
4. 关键机制消融。
5. 计算与扩展性。

## 8. 预期审稿质疑

### “这只是把 attention 写成积分”

回答需要依靠实际差异：无固定 index 参数、密度校正求积、训练/推理网格可变、明确的一致性目标、收敛测试和原生跨域映射。若这些差异不能带来性质或证据，质疑成立。

### “随机 patch augmentation 已经能做到”

用 B4 同等增强、参数/FLOPs 匹配以及布局/节点外推证明；若 B4 持平，缩小主张。

### “文本本来就是离散的，连续场没有意义”

承认 byte 边界离散；主张集中于内部状态与跨模态算子不依赖持久 token identity，而不是否认符号接口。必须用文本精确性压力测试避免模糊。

### “固定 basis coefficient 仍然是 token”

实现中避免固定 latent index；若使用 basis，说明其数值身份、可变阶数测试以及是否可在不同 basis 下得到一致场。

### “稳健性来自过度平滑”

报告高频、边界、小目标、OCR/数字压力测试和分辨率提升曲线。

### “为什么需要多模态？”

必须显示跨域算子在语言条件空间定位或关系推理中的作用；仅做图像重建不足以支撑论文标题。

## 9. 写作与复现检查

- 摘要中的每个结果数字都来自冻结脚本。
- 术语在全文一致，continuous、grid-independent、token-free 不混用。
- 图表展示不确定性，不只展示最好种子。
- 相关工作优先引用原始论文，准确说明重合与区别。
- 附录包含伪代码、复杂度、超参数、数据许可、种子和额外负结果。
- 发布匿名代码前去除身份信息、绝对路径和凭据。
