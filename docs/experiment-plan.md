# 实验计划

## 1. 实验原则

实验的首要任务不是证明 CMFO 一定更好，而是尽快区分三种可能：

1. 连续场算子确实带来网格外推和数值收敛；
2. 收益只是多分辨率增强或坐标编码产生的普通正则化；
3. 概念在任务精度、效率或文本离散结构上不可行。

每个正式运行都必须先登记假设、对照、主指标和停止条件，模板见 [experiment-log.md](experiment-log.md)。

## 2. 最小决定性系统

### 2.1 输入与状态

- 文本：完整 UTF-8 byte 与一维坐标；不删除 byte。
- 图像：RGB 与二维坐标；训练时使用规则网格、抖动网格或随机点采样。
- 隐场：每层可在不同求积点集合上求值；参数不依赖节点总数。
- 主干：4–8 个小型 residual operator blocks 用于验证，确认信号后再扩到 8–12 层。
- 输出：一个全局读取泛函和一个二维坐标解码头。

### 2.2 最小算子块

每个 block 只保留：

1. pointwise channel mixer；
2. 局部紧支撑核；
3. 低秩全局积分；
4. text↔image 双向积分；
5. residual update 与归一化。

第一轮不加入 ODE solver、flow matching、生成头、自适应网格或多模态共享生成空间。

## 3. 分阶段数据与任务

### E0：数值与结构正确性

使用解析函数和小型随机输入，不追求语义性能。

必须通过：

- 节点数组置换测试：保留坐标和值时，输出在数值容差内不变。
- 节点数变化测试：同一解析输入在 N、2N、4N 下误差呈稳定趋势。
- 布局变化测试：规则、抖动、随机点上不会崩溃或产生系统偏移。
- 批内可变长度/节点数测试。
- 梯度、混合精度、显存和吞吐 smoke test。
- 确认模型中不存在按最大节点数学习的 embedding 表。

### E1：可控多模态场景

构建程序化二维场景及组合文本描述/问题。同一潜在场景可渲染为多种分辨率和采样布局，从而拥有真正共享的底层内容。

建议任务：

- 全局：属性/关系问答或组合分类。
- 密集：由文本指定对象的 mask 或坐标场。

候选训练图像分辨率可取 32、48、64；测试加入未见的 40、56、80、96 以及等预算随机点云。具体集合在首个正式实验前冻结。文本始终保留完整 byte，仅改变内部求积网格。

E1 是 go/no-go 关卡：如果 CMFO 在这里没有稳定的网格外推优势，不进入昂贵真实数据训练。

### E2：真实小规模基准

目标是验证机制不依赖程序化数据。冻结前需审计许可、预处理和社区标准协议。

候选组合：

- 全局理解：COCO/Flickr 类图文检索，或一个公开 VQA 基准；
- 空间密集：RefCOCO/RefCOCO+ 类 referring expression grounding 或 segmentation；
- 压力测试：包含文字、细边界或小目标的子集，用于检测过度平滑。

优先选择一个全局任务和一个密集任务；不要为了任务数量牺牲强基线和完整消融。

### E3：投稿规模复验

仅当 E1 和 E2 都通过门槛后进行：

- 扩大模型和数据；
- 复验扩展趋势；
- 加入最接近的公开方法；
- 完整效率、鲁棒性、校准和失败案例分析。

## 4. 基线

所有核心基线使用相同训练样本、增强、步数和调参预算，并尽量提供参数/FLOPs 双重匹配版本。

| ID | 基线 | 回答的问题 |
|---|---|---|
| B0 | byte tokens + image patches 的标准 multimodal Transformer | 相对主流离散架构是否有价值 |
| B1 | pixel/point inputs + 连续坐标编码，但使用普通 attention | 收益是否只来自取消 patch |
| B2 | Perceiver-style 固定 latent array | 可变输入与固定 latent 是否已足够 |
| B3 | 与 CMFO 同结构但固定求积网格 | 随机网格和无持久节点是否必要 |
| B4 | B0/B1 加完全相同的多分辨率与采样增强 | 收益是否只是数据增强 |
| B5 | 最近、最强且公开可复现的连续/算子多模态方法 | 验证真实新颖性与竞争力 |

B5 必须在新颖性审计后具体化，不能用弱旧模型充当“相关工作”。

## 5. 核心实验矩阵

每个核心模型至少在下列轴上评估：

| 轴 | 训练设置 | 测试设置 | 目标 |
|---|---|---|---|
| 图像分辨率 | 若干离散分辨率 | 见过与未见、更低与更高 | 分辨率外推 |
| 求积点数量 | 一个区间内随机 N | 区间内与区间外 N | 节点数量稳健性 |
| 求积布局 | 规则 + 随机/抖动 | 规则、随机、非均匀 | 布局稳健性 |
| 查询密度 | 固定或随机 | 更稀与更密 | 输出场稳定性 |
| 数据分布 | 标准训练分布 | 组合、尺度、小目标等 shift | 语义稳健性 |
| 计算预算 | 多个宽度/深度/秩 | 同预算比较 | 扩展与效率 |

禁止只比较“CMFO 在随机网格测试”与“基线未接受同类训练”的不公平设置。

## 6. 指标

### 6.1 任务指标

- 全局任务：社区标准 accuracy、retrieval Recall@K 或 VQA score。
- 密集任务：mIoU、pointing accuracy、box accuracy 等与任务协议一致的指标。
- 压力子集：OCR/小目标/边界/组合关系的分组性能。

### 6.2 离散化指标

对同一底层样本在两个网格 G₁、G₂ 上比较：

- **输出一致性**：任务 logits、概率或解码输出之间的距离；
- **场一致性**：插值到共同查询点后的归一化 L2/余弦误差；
- **性能下降**：S(G_test) − S(G_reference)；
- **收敛曲线**：误差随 N 增加的 log–log 曲线与经验斜率；
- **布局敏感度**：同一 N 下不同采样规则的方差。

高密度数值解只能称为 reference approximation，除非存在解析真值。

### 6.3 效率与可靠性

- 参数量、训练/推理 FLOPs、峰值显存、样本/秒、延迟；
- 随 N 和图像尺寸变化的经验复杂度；
- 至少 3 个随机种子的均值、标准差或置信区间；
- 校准、失败率和数值异常数量。

## 7. 必做消融

按优先级：

1. 固定求积点 vs 每批随机点；
2. 有/无离散一致性损失；
3. 同等多分辨率增强下的离散基线；
4. 有/无局部核、低秩全局核、跨模态核；
5. 不同全局秩 R 与局部邻域 k；
6. 密度校正权重/求积权重；
7. 坐标编码类型及频率上限；
8. byte 与 BPE 边界输入的公平对照，但不混淆为同一信号重采样；
9. 固定 latent array 替代无持久网格；
10. 不同输出读取头，排除收益只来自 head。

若算力有限，先完成 1–5；不应先扩展模态或生成能力。

## 8. 公平比较与统计协议

- 在正式结果前冻结主指标、主要测试网格和验收容差。
- 基线与 CMFO 共享数据清洗、增强、优化器搜索范围和训练步数。
- 同时报参数匹配与 FLOPs 匹配；若二者无法兼得，分别报告。
- 每个主结果至少 3 个独立种子；小差异使用配对置信区间或适当检验。
- 调参只使用验证集和预先定义的网格，不查看测试 shift 选择模型。
- 报告最佳 checkpoint 规则，并保留逐步日志和完整配置。
- 所有失败、OOM、数值不稳定和排除运行都登记，不能只保留成功运行。

## 9. Go / No-Go 门槛

### Gate A：结构可行

E0 全部通过；模型无固定节点参数；换网格可直接推理；复杂度和梯度正常。

### Gate B：核心信号

在 E1 的全局与密集任务上，CMFO 的网格外推/一致性优势跨种子存在，且分布内性能位于预先冻结的可接受容差内。优势必须在 B4 的同等增强基线下仍存在。

### Gate C：真实迁移

至少两个互补真实任务复现主要趋势；强相关方法和标准 Transformer 对照完整；结果不是依靠显著更多计算。

### Gate D：投稿证据

主要消融、效率曲线、失败案例、理论或机制分析与复现材料齐全。未通过 Gate D 不以增加营销性主张代替证据。

门槛中的具体数值在 P1 结束、看到测试集结果之前登记到实验日志。

## 10. 失败诊断顺序

若无收益，依次检查：

1. 求积权重和坐标归一化是否正确；
2. 是否存在 aliasing、过高坐标频率或过度平滑；
3. 随机点是否导致训练噪声而非覆盖提升；
4. 低秩核或局部邻域是否形成容量瓶颈；
5. 跨模态更新是否坍缩为单向或常数场；
6. 基线是否因实现/调参差异被低估；
7. 核心假设是否应被拒绝。

前六项排除后仍失败，应记录负结果并重新评估路线，而不是默认扩大规模。
