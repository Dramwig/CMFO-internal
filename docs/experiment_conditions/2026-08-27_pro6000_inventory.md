## 已发现环境

服务器检查时存在以下 Conda 环境：

- base-py310-torch271-cu128
- disenclip
- pf-vlm
- routeledger-moellava

这些环境属于服务器现有资产。代码验证后建立了项目作用域的 CMFO 环境：

    /root/autodl-tmp/CMFO/.venv/bin/python

建立方式：

    /root/autodl-tmp/conda/envs/pf-vlm/bin/python \
      -m venv --system-site-packages /root/autodl-tmp/CMFO/.venv
    /root/autodl-tmp/CMFO/.venv/bin/python \
      -m pip install --no-deps -e /root/autodl-tmp/CMFO/CMFO-internal

验证版本：

- Python 3.10.20
- PyTorch 2.7.1+cu128
- CUDA runtime 12.8
- pytest 9.0.3
- PyYAML 6.0.3
- Ruff 0.16.4
- CMFO 0.1.0（editable）

该 venv 通过 system-site-packages 继承已核验的 pf-vlm 数值栈，避免复制大型
CUDA 环境；CMFO 自身和开发工具安装在项目作用域。若 pf-vlm 被升级或移除，
本环境必须重新核验，不能视为完全独立 lockfile。
