# 项目路线图

## 总体原则

路线按证据门槛推进，而不是按功能数量推进。任何阶段未通过退出条件，都先诊断或收缩主张，不自动进入更大模型、更大数据或更多模态。

## 阶段概览

| 阶段 | 目标 | 主要产物 | 退出条件 | 状态 |
|---|---|---|---|---|
| P0 | 冻结问题与新颖性 | 相关工作矩阵、术语、核心主张、预算 | C1 可清楚辩护；实验协议可证伪 | 进行中 |
| P1 | 最小实现正确 | 数据接口、小型 CMFO、B0–B4、单元测试 | Experiment Gate A | 已完成 |
| P2 | 可控证据 | E1 主结果、消融、失败分析 | Experiment Gate B | 未开始 |
| P3 | 真实任务迁移 | E2 两类任务、强最近方法 | Experiment Gate C | 未开始 |
| P4 | 投稿级复验 | 多种子、规模曲线、理论/机制、效率 | Experiment Gate D | 未开始 |
| P5 | 写作与复现 | 完整论文、附录、匿名代码、检查表 | 内部审稿无关键证据缺口 | 未开始 |

## P0：问题定义与新颖性审计

### 任务

- 建立最近相关工作矩阵，优先读原始论文和官方实现。
- 明确定义观测点、求积点、查询点、持久身份和离散化不变性。
- 确认 CMFO 与 continuous attention、neural operator、Perceiver、pixel/byte models 的最小差异。
- 选择 E1 数据生成规则和 E2 候选任务。
- 冻结首轮计算预算、主指标、网格集合和容差登记流程。

### 退出条件

- 能用一句非营销语言说清创新。
- 至少找出 3 个最接近方法，并写明可验证差异。
- C1–C5 各有对应实验或被删除。
- 不依赖测试结果的验收协议已登记。

## P1：最小实现与正确性

状态：2026-08-27 完成，Gate A 通过。证据见
[代码验证记录](records/2026-08-27_code_validation_v2.md)。

### 任务

- 建立统一的坐标化观测与可变节点 batching。
- 实现小型 lifting、operator block、跨模态算子和两个读取头。
- 实现 B0–B4，尽量复用数据和训练框架。
- 加入置换、网格、梯度、数值稳定和复杂度测试。
- 构建程序化场景生成器和解析/高精度参考。

### 退出条件

- E0 全部通过。
- 参数形状不依赖最大节点数。
- 任意已登记网格可无结构修改推理。
- 单批过拟合和小规模训练均正常。
- 基线和 CMFO 的预算统计可信。

## P2：可控多模态证据

### 任务

- 运行 E1 的全局与密集任务。
- 完成 B0–B4、公平增强和优先级 1–5 的消融。
- 绘制节点数、布局、分辨率和效率曲线。
- 检查高频边界、文字精确性和过度平滑。
- 根据证据接受、缩小或拒绝 H1–H3。

### 退出条件

- Gate B 通过。
- 结果跨种子、任务和至少两类 shift 成立。
- 核心收益不能被单一普通增强解释。
- 已有足够证据决定是否值得真实数据投入。

## P3：真实任务迁移

### 任务

- 冻结一个全局与一个密集真实任务。
- 复现标准基线与审计后确定的 B5。
- 完成参数/FLOPs 匹配、调参记录和许可检查。
- 分析小目标、OCR/符号、长文本和非均匀分辨率子集。

### 退出条件

- Gate C 通过。
- 主趋势至少在两个互补任务成立。
- 与最接近方法的差异能由数据而非叙述支持。
- 已明确论文是通用方法、稳健性方法，还是受限负/诊断结果。

## P4：投稿级复验

### 任务

- 进行多规模、多种子最终复验。
- 完成所有必须消融、效率、校准和失败案例。
- 完成最现实的理论命题并核对假设。
- 冻结主文图表生成脚本。
- 开展至少一次独立复现。

### 退出条件

- Gate D 通过。
- 论文所有主张都能追溯到证据。
- 不存在只靠隐藏计算预算或弱基线成立的结论。
- 所有主数字可由干净环境复现。

## P5：写作与内部审稿

### 任务

- 按 [paper-plan.md](paper-plan.md) 完成主文和附录。
- 邀请至少三类内部读者：神经算子、视觉语言、一般 ML。
- 分别进行 novelty、correctness、empirical rigor 和 clarity 审查。
- 做匿名化、引用、许可、伦理与复现检查。

### 退出条件

- 摘要、引言、方法和实验使用同一套主张。
- 每个预期质疑都有数据、理论或诚实限制回应。
- 页数压缩未删除关键公平性或负结果。
- 匿名仓库和补充材料可独立运行。

## P6：投稿

### 任务

- 根据完成时间、论文形态和会议征稿范围选择 NeurIPS、ICLR 或 ICML。
- 核对当届官方格式、匿名政策、补充材料和截止时间。
- 准备 rebuttal evidence map：每项潜在质疑对应现有表、图或可在允许范围内补充的分析。

会议规则和截止日期可能变化，必须在投稿时以官方页面为准，不在本路线图硬编码。

## 当前最高优先级

1. 完成新颖性审计矩阵。
2. 冻结 Gate B 的数值容差、正式 seeds 与计算预算。
3. 运行 E1 的 CMFO、B0–B4 参数/FLOPs 匹配实验。
4. 完成局部、全局、跨模态和一致性损失消融。
5. 根据 E1 证据决定是否进入真实数据任务。

## 延后队列

- 连续深度/Neural ODE。
- adaptive mesh refinement。
- 文本或图像生成。
- 音频、视频和 3D。
- 大模型规模预训练。
- “涌现实体”的可解释性研究。

只有首篇主线通过 Gate C 后，才评估这些方向是否进入同一论文、后续论文或独立项目。
