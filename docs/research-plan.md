# 研究计划

## 1. 工作题目

推荐主标题：

**Continuous Multimodal Field Operators for Discretization-Invariant Vision–Language Learning**

标题中的 token-free 只可作为受限定的副标题或宣传语，不能替代准确的技术定义。

## 2. 问题定义

标准多模态模型通常把文本、图像或共享 latent 表示为有限数组。它们可以处理可变长度和可变分辨率，但模型的状态与计算仍常依赖具有持久位置身份的 token、patch 或 latent slot。CMFO 要研究的不是“序列长度能否变化”，而是：

> 能否用原生坐标域上的函数状态和网格无关的算子参数化多模态计算，并让同一底层内容在不同数值离散下得到一致、收敛且任务有效的结果？

### 2.1 三类节点必须分开

- **观测点**：输入边界数据，例如 byte 或像素。它们可携带真实信息，不一定可随意删除。
- **求积点**：近似积分和隐场计算的数值节点。它们不应拥有持久语义身份，可改变数量和布局。
- **查询点**：读取输出场的位置。它们决定输出接口的精度，不应改变底层预测语义。

论文中的“无持久离散语义单元”主要约束内部求积状态，而不是否认观测和输出的离散性。

### 2.2 文本的特殊边界

UTF-8 byte 是符号数据，不是可无损下采样的连续物理信号。首篇论文不声称删减或插值 byte 后语义不变。文本侧可合法检验：

- 完整 byte 观测在不同内部求积点数量和布局下的一致性；
- 坐标区间缩放或长度归一化的稳定性；
- 输入数组置换但保留绝对坐标后的等价性；
- 经严格定义的、信息等价的边界编码映射。

若没有可逆映射，不把 UTF-8、Unicode code point 或 BPE 视为同一信号的普通重采样。

## 3. 中心假设

### H1：离散化一致性（核心）

对于同一底层输入，改变内部求积网格的节点数、位置或规则后，CMFO 的场预测和任务输出比匹配基线更稳定，并随求积精度增加趋于收敛。

### H2：原生几何的跨模态耦合（核心）

分别保留文本一维域和图像二维域，通过跨域积分算子交互，可在全局理解和空间密集任务上学习有效对齐，而不需要先把两者拼成统一 token 序列。

### H3：任务竞争力（核心）

在训练数据、参数量和优化预算匹配时，CMFO 的标准分布内任务性能不应因稳健性收益而出现不可接受的下降。

### H4：效率或尺度优势（扩展）

局部核与低秩全局核可能带来优于二次 attention 的扩展趋势。除非实测成立，否则不作为核心贡献。

## 4. 论文主张与证据

| 编号 | 候选主张 | 最低必要证据 | 失败时的处理 |
|---|---|---|---|
| C1 | 提出无持久语义网格的文本–图像场算子 | 明确数学定义、实现对应关系、架构图、与最近工作的逐项对比 | 若仅是连续位置编码的 attention，撤回结构新颖性主张 |
| C2 | 对未见求积离散具有一致性和收敛性 | 多节点数、多布局、多分辨率；场级与任务级指标；至少 3 个种子 | 若只在训练网格有效，改为普通数据增强方法 |
| C3 | 原生域耦合支持有效多模态推理 | 一个全局任务、一个密集任务、强多模态基线与跨算子消融 | 若只在合成数据有效，不主张通用视觉语言方法 |
| C4 | 任务性能与强离散基线有竞争力 | 参数、FLOPs、数据、训练步数匹配；置信区间与效率曲线 | 若差距过大，研究稳健性–精度权衡而非替代性 |
| C5 | 随机求积与一致性目标是收益来源 | 固定/随机网格、无一致性损失、同等增强基线 | 若简单增强解释收益，缩小算法贡献 |

C1–C4 是投稿主线。C5 用来解释机制。效率、生成、ODE 和更多模态均为可选扩展。

## 5. 首篇论文范围

### 包含

- 模态：文本与静态图像。
- 输入：完整 UTF-8 byte 观测；RGB 坐标观测，可使用规则或随机采样。
- 主干：连续 lifting、点态通道混合、局部算子、低秩全局算子、双向跨模态算子、残差更新。
- 输出：全局任务泛函与二维密集输出场。
- 评价：分布内性能、未见图像分辨率、内部节点数、采样布局、数值收敛、效率和校准。

### 不包含

- 大规模任意模态生成。
- 对“意识”“涌现实体”等不可直接测量概念的结论。
- 以固定层数是否“真正连续”为论文争论中心。
- 仅凭可变长度、连续位置编码或随机 patch 就声称算子一致性。

## 6. 方法必须满足的结构约束

1. 可学习参数形状不依赖输入分辨率、文本长度和求积节点数。
2. 求积节点没有固定可学习 index embedding 或持久槽身份。
3. 积分近似显式使用坐标和与采样密度相容的权重。
4. 对无序节点数组，置换数据存储顺序不改变结果；文本顺序由坐标表达。
5. 同一模型可在训练未见的节点数量和布局上直接推理。
6. 输出场可在不同查询网格上读取，且结果随查询加密稳定。
7. 任何违反上述约束的工程折中必须在论文中标明。

## 7. 理论目标

最低目标是给出清晰的离散算子与连续目标算子之间的对应关系。若核函数、隐藏状态和点态变换满足适当的有界性/Lipschitz 条件，求积规则误差为 ε(G)，希望建立类似下式的层间稳定性或误差传播结论：

 ‖I_G F_{θ,G}(P_G x) − F_θ(x)‖ ≤ C(T, θ) ε(G)。

可接受的理论层级按优先级排列：

1. 有限深度残差算子的求积一致性与误差传播界；
2. 跨模态耦合算子的稳定性条件；
3. 原生域变换下的等变性命题；
4. 连续深度极限，仅在不分散主线时研究。

理论不得假设实际模型不满足的全局光滑性，也不得把经验参考网格当作真实连续解。

## 8. 新颖性审计

在实现大模型前建立相关工作矩阵，至少覆盖：

- neural operators：FNO、DeepONet、图/核积分算子及多分辨率学习；
- continuous/linear attention 与 attention-as-integral-operator；
- implicit neural representations、coordinate networks、neural fields；
- patch-free、pixel-level、byte-level 与 tokenizer-free 模型；
- Perceiver、latent array、set models 与多模态 cross-attention；
- resolution extrapolation、mesh invariance、Monte Carlo quadrature；
- 多模态 dense prediction 和原生几何保留方法。

矩阵至少包含：基本状态类型、是否有持久 latent identity、参数是否依赖网格、模态原生域、跨模态机制、是否测试数值收敛、理论保证、训练规模和主要局限。

只有完成该矩阵后，才能冻结 C1 的准确表述。若完整组合已有先例，贡献必须转向新的理论、训练准则或实证发现。

## 9. 反证与停止条件

以下任一结果都会削弱当前主张：

- 更换求积网格后输出变化与离散基线相当，且增加节点不收敛。
- 收益完全由多分辨率数据增强解释。
- 随机节点只是正则化，固定 latent 或 patch 基线在同等设置下同样有效。
- 分布外稳健性来自严重平滑，导致密集边界、OCR、数字或组合推理显著退化。
- 参数/FLOPs 匹配后标准任务性能差距过大。
- 方法实际依赖固定 basis index，形成另一种持久 token。
- 核积分实现退化为普通 attention，且没有新的性质或证据。

出现反证时先记录，再决定缩小主张、改变方法或停止该路线；不得只通过增加模型规模掩盖问题。

## 10. 投稿级成功标准

- 新颖性：与最接近的 3–5 个方法存在可验证且重要的差异。
- 机制：核心收益能由必要的消融定位，而非模糊归因于规模。
- 证据：至少一个可控基准与两个互补的真实任务，覆盖全局和密集输出。
- 稳健性：未见分辨率、节点数和采样布局均有系统曲线，不只报单点。
- 公平性：强基线有相同数据、预算和增强，报告不确定性和负结果。
- 复现性：代码、配置、环境、数据清单、随机种子和原始日志完整。
